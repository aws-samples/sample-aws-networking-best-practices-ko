# AWS Networking Best Practices — Korean & Japanese Edition (KO/EN/JA)

A trilingual (Korean / English / Japanese) site for **AWS networking best practices**. It mirrors and
translates [aws/aws-networking-best-practices](https://github.com/aws/aws-networking-best-practices)
into Korean and Japanese, and additionally curates **AWS What's New**, **Networking blog**,
and **AWS Korea/Japan tech blog** updates — automatically filtered for networking topics
and summarized in all three languages.

🔗 **Site:** https://aws-samples.github.io/sample-aws-networking-best-practices-ko/

> ⚠️ The Korean and Japanese text is an unofficial machine translation. Always refer to the English original for authoritative content.

## What you'll find

- **Networking best practices** — the full guide (foundation, connectivity, application networking, security, observability), in Korean, English, and Japanese.
- **News** — networking-relevant AWS What's New announcements and Networking & Content Delivery / AWS Korea / AWS Japan blog posts, automatically collected and summarized (KO/EN/JA).
- **Trilingual** — switch languages anytime from the header (Korean at `/`, English at `/en/`, Japanese at `/ja/`).

Regenerating the translations and news requires AWS Bedrock access — see [`deploy/README.md`](deploy/README.md).
